# Honeymoon

## GitHub Pages 게시

이 ZIP을 해제한 뒤 index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, .nojekyll을 동일 폴더에 올립니다. ZIP 자체를 업로드하는 것이 아닙니다.

기존 사이트가 없는 전용 저장소 사용을 권장합니다. 저장소 루트에 위 파일을 업로드하고 Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save를 선택하세요. 표시되는 HTTPS Pages 주소를 사용합니다. 기존 index.html이 있다면 덮어쓰지 말고 별도 저장소나 하위 폴더를 선택하세요.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 휴대폰 설치

- iPhone: Pages 주소를 Safari에서 열고 공유 → 홈 화면에 추가. 웹 앱으로 열기 옵션이 있으면 켭니다.
- Android: Chrome에서 Pages 주소 → 메뉴 → 앱 설치 / 홈 화면에 추가. 또는 앱의 설정 탭에서 홈 화면 설치를 선택합니다.
- 파일 미리보기에서는 JavaScript 실행, 설치, 로컬 저장이 제한될 수 있습니다. 실제 Pages 주소를 Safari·Chrome에서 여세요.
- 처음 온라인에서 캐시가 완료된 후 일정 화면을 오프라인으로 사용할 수 있습니다. Google 지도·예약 링크는 인터넷이 필요합니다. OS가 저장 공간을 정리하면 오프라인 데이터가 사라질 수 있으므로 JSON 백업을 보관하세요.

## 데이터 보존

현재 브라우저에 저장되며 기기 간 자동 동기화는 없습니다. 설정 → JSON 백업 → 다른 기기에서 백업 가져오기를 사용하세요. Safari와 홈 화면 앱에서도 최초에 백업 가져오기가 필요할 수 있습니다. 이전 v1 배열 JSON / v2 일정·예산 JSON을 지원합니다. 같은 출처에 기존 저장값이 있으면 자동으로 읽어 v3로 옮기며 이전 키는 삭제하지 않습니다.

초기 일정·예약 상태·예산은 이전 파일을 보존한 것입니다. 초기 예산에는 예시·추정 및 결제 여부 미검증 항목이 포함됩니다. 실제 예약·결제 확인이 아닙니다. 공식 링크의 실시간 재고도 확인하지 않았습니다.

예약 링크와 비용은 별도 탭에 있으며 메인에서 비용 문구는 숨깁니다. 비용 탭의 원본 메모에서 전체 문구를 확인·수정할 수 있습니다. 그 날의 지도는 숙소 중심 지도로 표시하고 예약 항목별 지도 링크를 제공합니다. 경유지 최적화·실시간 이동시간 계산 기능은 아닙니다.

## 공개 범위

기본 일정과 숙소, 초기 예산이 index.html 안에 포함되어 있습니다. GitHub Pages로 공개하면 다른 사람도 볼 수 있습니다. 민감한 개인정보·여권·예약번호를 소스에 넣지 마세요. 기기에서 편집한 값은 서버나 GitHub에 자동 업로드되지 않습니다. 이 파일 묶음을 만든 것만으로 사이트가 게시되지는 않습니다.

## 수정 및 업데이트

index.html을 수정 후 같은 위치에 업로드합니다. 앱 셸을 업데이트할 때 sw.js의 CACHE 버전(v3-1)을 변경하세요. 브라우저 로컬 데이터는 코드 캐시와 분리되어 보존됩니다. 먼저 백업을 받은 뒤 업데이트하세요.
